# Security Policy

## Supported versions

Only the current `main` branch is supported; there are no maintained older versions.

## Reporting a vulnerability

This repo is a VS Code color theme (a static JSON theme definition) — it has no build step
and runs no code. If you find a vulnerability here, please report it privately using GitHub's
**Report a vulnerability** button on this repo's
[Security tab](https://github.com/matthewjschultz/black-pearl-ii-vscode/security/advisories/new).

Please do not open a public issue for security reports.
